# LZMA SDK（计划引入，尚未随包分发）

- 上游：https://www.7-zip.org/sdk.html
- 许可：**公有领域（public domain）**
- 计划用途：7z 的 LZMA / LZMA2 块解码（`LzmaDec.c`、`Lzma2Dec.c`、`Bcj2.c`，可选 `Aes.c`）

## 义务

无强制义务。上游声明 LZMA SDK 置于公有领域，可自由使用、修改与再分发（含商业用途）。
保留来源说明是良好实践，不是许可要求。

## 边界

- ✅ 只取 SDK 的**解码**部分；
- ❌ 不要把整个 `7zz`（归档工具）编译进来：那是 LGPL-2.1+，会带来提供源码、允许重新链接等义务；
- ❌ 不要引入 RAR 相关代码（见 `unrar.md` 的限制条款）；
- 商标：不要用 "7-Zip" 作为插件名，描述性提及（"支持 7z 格式"）没有问题。

## 引入时要做

1. 在 `wasm/` 下保存来源版本与官方 LICENSE 片段；
2. 在本文件补充实际使用的文件清单与版本；
3. 更新 `NOTICE.md` 与 `README.md` 的"随包分发"表格。
